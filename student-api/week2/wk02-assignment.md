# ใบงานส่งสัปดาห์ที่ 2

## รายละเอียด

ให้นิสิตส่งหลักฐานการทำปฏิบัติการสัปดาห์ที่ 2 (`wk02-lab.md`: เปรียบเทียบ REST และ GraphQL ด้วยการทดลองจริง) ตามหัวข้อต่อไปนี้

1. **ซอร์สโค้ด** ไฟล์ `index.js`, `schema.js`, `resolvers.js` ของโปรเจกต์ `student-api` ที่มีทั้ง REST endpoint (`/api/v1/students/:id`) และ GraphQL endpoint (`/graphql`) พร้อมข้อมูลจำลองที่มีความสัมพันธ์ระหว่างนิสิตและรายวิชา
2. **ผลการทดลองเปรียบเทียบ** ภาพหน้าจอหรือบันทึกผลลัพธ์จาก
   - REST endpoint `/api/v1/students/1/full` (แสดงปัญหา over-fetching)
   - GraphQL Query ที่ขอเฉพาะ `name` และ `courses.courseName` (ขั้นตอนที่ 3.5 ใน `wk02-lab.md`)
   - GraphQL Query ที่รวมข้อมูลนิสิตทุกคนพร้อมรายวิชาในคำขอเดียว (ขั้นตอนที่ 3.6)
3. **ตารางสรุปผลการเปรียบเทียบ** ตามรูปแบบในขั้นตอนที่ 3.7 ของ `wk02-lab.md` (จำนวนคำขอ และฟิลด์ที่ได้รับเกินความจำเป็น)

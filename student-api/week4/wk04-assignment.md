# ใบงานส่งสัปดาห์ที่ 4

## รายละเอียด

ให้นิสิตส่งหลักฐานการทำปฏิบัติการสัปดาห์ที่ 4 (`wk04-lab.md`: เพิ่มชั้นความปลอดภัยพื้นฐานด้วย Middleware) ตามหัวข้อต่อไปนี้

1. **ซอร์สโค้ด** ไฟล์ `index.js` ของโปรเจกต์ `student-api` (และไฟล์ในโฟลเดอร์ `routes/` ด้วย หากทำแบบฝึกหัดต่อยอดสัปดาห์ที่ 1 แยก route ออกจาก `index.js` แล้ว) ที่มี Helmet, CORS, Logger (`morgan`), Environment Variables (`dotenv`) และ Error-Handling Middleware ครบถ้วน พร้อมไฟล์ `.env.example` (ห้ามส่งไฟล์ `.env` จริงที่มีข้อมูลลับ)
2. **ผลการทดสอบ Header และ Error Format** ภาพหน้าจอจาก Postman ที่แสดง
   - Response Header จาก Helmet (ขั้นตอนที่ 3.1 ใน `wk04-lab.md`)
   - ผลการทดสอบ error response มาตรฐานครบทั้ง 4 กรณีในตารางขั้นตอนที่ 3.3
3. **บันทึกผลการทดสอบ Attack Scenario** สรุปสั้น ๆ ว่าทดสอบ payload ขนาดใหญ่ (ขั้นตอนที่ 3.4) และ type confusion (ขั้นตอนที่ 3.5) ได้ผลอย่างไร พร้อมข้อสังเกตของตนเอง

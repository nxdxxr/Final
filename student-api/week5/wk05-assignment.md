# ใบงานส่งสัปดาห์ที่ 5

## รายละเอียด

ใบงานนี้เป็นหลักฐานแสดงความรับผิดชอบในการทำปฏิบัติการสัปดาห์ที่ 5 (CLO1) แยกต่างหากจากโครงงานระยะที่ 1 DB/Requirement (`wk05-project-phase1.md` ซึ่งวัด CLO8) โดยไม่มีการให้คะแนนเชิงคุณภาพซ้ำซ้อนกับสิ่งที่โครงงานตรวจอยู่แล้ว เป็นเพียงการยืนยันว่าได้ลงมือทำปฏิบัติการจริงตาม `wk05-lab.md` กับโปรเจกต์ตัวอย่าง `student-api`

## สิ่งที่ต้องส่ง

1. ภาพหน้าจอ (screenshot) ผลการทดสอบ Rollback ครบทั้ง 3 กรณีตามตารางในขั้นตอนที่ 3.4 ของ `wk05-lab.md` (ลงทะเบียนสำเร็จ, รายวิชาไม่มีอยู่จริง, ลงทะเบียนซ้ำ) รวมเป็นไฟล์เดียว
2. index.js ที่เพิ่ม Endpoint ในส่วนต่อยอด: แบบฝึกหัดที่ 1, 2, 3

```
wk05-<รหัสนิสิต>/
└── index.js
└── rollback-test-results.pdf
```

## เกณฑ์การให้คะแนน

คะแนนเต็ม 1 คะแนน ให้แบบผ่าน/ไม่ผ่าน (Pass/Fail) ไม่มีการให้คะแนนย่อยเชิงคุณภาพ เนื่องจากคุณภาพของการออกแบบฐานข้อมูลถูกวัดแล้วในโครงงานระยะที่ 1

| เงื่อนไข                                    | คะแนน |
| ------------------------------------------- | ----- |
| ส่งไฟล์ครบ และหลักฐานการทดสอบครบทั้ง 3 กรณี | 1.0   |
| ส่งไม่ครบหรือไม่ตรงเวลา                     | 0     |

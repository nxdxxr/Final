# ใบงานส่งสัปดาห์ที่ 6

## รายละเอียด

ให้นิสิตส่งหลักฐานการทำปฏิบัติการสัปดาห์ที่ 6 (`wk06-lab.md`: Implement ระบบ Authentication และ RBAC) ตามหัวข้อต่อไปนี้

1. **ซอร์สโค้ด** ไฟล์ `index.js`, `auth-helpers.js`, `middlewares/auth.js` ของโปรเจกต์ `student-api` ที่มีระบบ Register, Login, Token Middleware และ RBAC Middleware ครบถ้วน พร้อมสคริปต์ SQL สร้างตาราง `users`
2. **ผลการทดสอบ Protected Route และ RBAC** ภาพหน้าจอจาก Postman ที่แสดงผลครบทั้ง 5 กรณีตามตารางในขั้นตอนที่ 3 ของ `wk06-lab.md` ได้แก่ ไม่แนบ Token, Token ถูกต้อง, ลบข้อมูลด้วยบทบาท student (ถูกปฏิเสธ), ลบข้อมูลด้วยบทบาท admin (สำเร็จ), และ Token ที่ถูกแก้ไข
3. **คำอธิบายสั้น ๆ** (ไม่เกินครึ่งหน้า) อธิบายว่าเหตุใด token ที่ถูกแก้ไขแม้เพียงตัวอักษรเดียวจึงถูกปฏิเสธ โดยอ้างอิงหลักการ Signature ใน `wk06.md`

# ใบงานส่งสัปดาห์ที่ 3

## รายละเอียด

ใบงานนี้เป็นหลักฐานแสดงความรับผิดชอบในการทำปฏิบัติการสัปดาห์ที่ 3 (CLO1) แยกต่างหากจากสอบวัดผลออกแบบ (CLO3) ซึ่งจัดสอบรวมอยู่ในคาบสอบปลายภาค สัปดาห์ที่ 16 (ดูรายละเอียดที่ `wk03-exam.md` และ `final-exam.md`) โดยไม่มีการให้คะแนนเชิงคุณภาพซ้ำซ้อนกับสิ่งที่สอบวัดผลตรวจอยู่แล้ว เป็นเพียงการยืนยันว่าได้ลงมือทำปฏิบัติการจริงตาม `wk03-lab.md`

## สิ่งที่ต้องส่ง

ส่งไฟล์ `URI-SCHEMA.md` ที่จัดทำในขั้นตอนที่ 2.5 ของ `wk03-lab.md` พร้อมแบบฟอร์ม Peer Check ที่กรอกครบถ้วนจากขั้นตอนที่ 3.1 (ตรวจให้เพื่อน 1 ฉบับ)

```
wk03-<รหัสนิสิต>/
├── URI-SCHEMA.md
└── peer-check-form.md
```

## เกณฑ์การให้คะแนน

คะแนนเต็ม 1 คะแนน ให้แบบผ่าน/ไม่ผ่าน (Pass/Fail) ไม่มีการให้คะแนนย่อยเชิงคุณภาพ เนื่องจากคุณภาพของการออกแบบถูกวัดแล้วในสอบวัดผลออกแบบ (Final, สัปดาห์ที่ 16)

| เงื่อนไข                          | คะแนน |
| --------------------------------- | ----- |
| ส่งไฟล์ครบทั้ง 2 รายการภายในกำหนด | 1.0   |
| ส่งไม่ครบหรือไม่ตรงเวลา           | 0     |

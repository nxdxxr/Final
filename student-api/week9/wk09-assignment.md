# ใบงานส่งสัปดาห์ที่ 9

## รายละเอียด

ใบงานนี้เป็นหลักฐานแสดงความรับผิดชอบในการทำปฏิบัติการสัปดาห์ที่ 9 (CLO1) เรื่องการเขียน Unit และ Integration Test ด้วย Jest และ Supertest ตาม `wk09-lab.md` ประเมินแบบผ่าน/ไม่ผ่าน (Pass/Fail) โดยไม่ให้คะแนนเชิงคุณภาพซ้ำซ้อนกับสอบปฏิบัติ Testing/Validation (CLO4) ที่จัดสอบรวมอยู่ในคาบสอบปลายภาค สัปดาห์ที่ 16 (ดู `course_plan.md` แถวสัปดาห์ที่ 16) เป็นเพียงการยืนยันว่าได้ลงมือทำปฏิบัติการจริงตาม `wk09-lab.md` กับโปรเจกต์ตัวอย่าง `student-api`

## สิ่งที่ต้องส่ง

ภาพหน้าจอ (screenshot) ผลลัพธ์การรันคำสั่ง `npm run test:coverage` จากขั้นตอนที่ 3.2 ของ `wk09-lab.md` ที่แสดงตาราง Coverage ครบทุกคอลัมน์ (`% Stmts`, `% Branch`, `% Funcs`, `% Lines`) พร้อมบรรทัดสรุปจำนวน `Test Suites` และ `Tests` ที่ผ่านทั้งหมด

```
ส่งไฟล์ wk09-<รหัสนิสิต>-test-coverage-report.pdf
```

## เกณฑ์การให้คะแนน

คะแนนเต็ม 1 คะแนน ให้แบบผ่าน/ไม่ผ่าน (Pass/Fail) ไม่มีการให้คะแนนย่อยเชิงคุณภาพ เนื่องจากคุณภาพของการเขียน test ถูกวัดแล้วในสอบปฏิบัติ Testing/Validation (Final, สัปดาห์ที่ 16)

| เงื่อนไข                                                          | คะแนน |
| ------------------------------------------------------------------ | ----- |
| ส่งหลักฐานภายในกำหนด และ `Test Suites`/`Tests` แสดงผลผ่านทั้งหมด | 1.0   |
| ส่งไม่ครบ ไม่ตรงเวลา หรือมี test ที่ล้มเหลว (FAIL)                | 0     |

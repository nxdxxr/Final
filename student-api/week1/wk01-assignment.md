# ใบงานส่งสัปดาห์ที่ 1

## รายละเอียด

ให้นิสิตส่งหลักฐานการทำปฏิบัติการสัปดาห์ที่ 1 (`wk01-lab.md` ส่วนที่ 2: สร้าง Skeleton CRUD และทดสอบด้วย Postman) ตามหัวข้อต่อไปนี้

1. **ซอร์สโค้ด** ไฟล์ `index.js` ของโปรเจกต์ `student-api` ที่มี route ครบทั้ง 5 เส้นทาง (`GET /students`, `GET /students/:id`, `POST /students`, `PUT /students/:id`, `DELETE /students/:id`) พร้อม `package.json`
2. **ผลการทดสอบด้วย Postman** ภาพหน้าจอ (screenshot) หรือไฟล์ Postman Collection (export เป็น `.json`) ที่แสดงผลการทดสอบครบทั้ง 6 กรณีตาม `wk01-lab.md` ได้แก่ ดึงรายการทั้งหมด, เพิ่มข้อมูล, ดึงข้อมูลรายบุคคล, แก้ไขข้อมูล, ลบข้อมูล และกรณีไม่พบข้อมูล (404)
3. **คำอธิบายโครงสร้างโปรเจกต์สั้น ๆ** (ไม่เกินครึ่งหน้า) ตอบคำถามจากขั้นตอนที่ 3.2 ใน `wk01-lab.md` ว่าหากมี route เพิ่มขึ้นอีก 10 เส้นทาง โค้ดในไฟล์เดียวจะเกิดปัญหาใด

## รูปแบบการส่ง

ส่งเป็นไฟล์ zip ที่มีโครงสร้างไฟล์ดังนี้

```
wk01-<รหัสนิสิต>/
├── index.js
├── package.json
├── postman-collection.json   (หรือไฟล์ภาพหน้าจอผลการทดสอบ)
└── README.md                  (คำอธิบายโครงสร้างโปรเจกต์ตามข้อ 3)
```
